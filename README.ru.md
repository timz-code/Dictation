# Dictation

[English](README.md)

Нативное приложение для строки меню macOS. Удерживайте **Control + 🌐 (Globe / Fn)**, говорите, отпустите любую из двух клавиш — локальный Whisper распознает речь и отправит текст в исходное поле ввода через ⌘V.

Apple GPU через Metal/MPS, отдельный CPU-режим, живой зеркальный спектр голоса, отдельная анимация распознавания, индикатор снизу/по центру/сверху. Без аккаунта, API-ключа и подписки.

## Zero Internet Connection

**Dictation работает полностью локально. Аудио и расшифровки обрабатываются на вашем Mac и не отправляются приложением на серверы. Программа не делает никаких обращений в Интернет.**

У Dictation нет серверов, сетевых API, аналитики, телеметрии, проверки обновлений, скачивания моделей или локального HTTP-сервера. Swift-приложение и Python-процесс обмениваются данными через локальные stdin/stdout. Whisper использует существующую папку модели: отсутствие файлов приводит к ошибке, а не к скачиванию. Принудительно включён офлайн-режим Hugging Face, отключена телеметрия Hugging Face и ONNX Runtime.

Запись хранится в приватной временной папке с доступом только для владельца и удаляется после распознавания, отмены, ошибки или штатного выхода. При аварийном завершении временный файл может остаться. Последняя расшифровка хранится только в оперативной памяти; истории на диске нет. В настройках сохраняются параметры и локальные пути, но не продиктованный текст. Записи в буфер обмена помечаются системным флагом **только для этого Mac** и не публикуются Dictation через Universal Clipboard.

Это относится к приложению и процессу распознавания во время использования. Первоначальная установка инструментов, Python-пакетов и файлов модели выполняется отдельно и может потребовать Интернет. Программа, в которую вы вставляете текст, и сторонние менеджеры буфера имеют собственные правила хранения и передачи данных; Dictation ими не управляет.

## Требования, сборка и запуск

Нужны macOS 14+, Xcode / Swift 5.9+, локальное окружение Python с faster-whisper и полная модель в формате CTranslate2. Проверенные версии зависимостей указаны в [requirements.txt](requirements.txt); Python и веса модели не входят в приложение. Для GPU нужен Apple Silicon и сборка CTranslate2 с экспериментальным MPS-бэкендом; проверенная установка использует CTranslate2 4.9.1. При недоступности GPU программа сообщает об ошибке, а не переключается на CPU молча.

```sh
bash scripts/build.sh
open dist/Dictation.app
```

Используйте скрипт: он включает Python-worker, переводы и описания разрешений macOS в `.app`. Сам Swift-executable не является полным приложением.

По умолчанию используются существующие пути:

```text
~/.local/share/whisper-ru/venv/bin/python
~/.local/share/whisper-ru/model/
```

Папка модели должна содержать `model.bin`, `config.json`, `tokenizer.json`, `preprocessor_config.json` и файлы словаря, поставляемые с моделью. Для русского нужна многоязычная модель. Если установка находится в другом месте, измените пути в настройках распознавания. Dictation не устанавливает пакеты и не меняет существующий Whisper. Наличие MPS зависит от сборки CTranslate2, а не только номера версии.

При первом запуске:

1. Разрешите микрофон.
2. Включите **Dictation.app** в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».
3. Дождитесь готовности модели, закройте настройки и установите курсор в поле ввода.
4. Зажмите Control + 🌐, скажите фразу и отпустите клавиши.

Разрешения перепроверяются автоматически. Если сочетание недоступно, разрешите Dictation также в «Мониторинг ввода» и перезапустите приложение. Secure Input и защищённые поля могут блокировать сочетания или вставку.

Если Globe меняет раскладку или включает системную диктовку, выберите «Клавиатура → Нажатие клавиши 🌐 → Ничего не делать». Проверьте своё сочетание для смены раскладки, обычно Control + Space. Приложение не меняет системные назначения.

## Язык и настройки

- **Язык интерфейса: Как в системе / English / Русский.** В автоматическом режиме русский включается, если основной предпочитаемый язык macOS — русский; иначе используется английский. Ручной выбор сохраняется и применяется сразу, без перезагрузки модели.
- **Язык речи** настраивается отдельно: русский, английский или автоопределение. Существующий выбор сохраняется. При новой установке выбирается русский для русского интерфейса, иначе автоопределение.
- **Положение индикатора:** снизу, по центру или сверху. Выбор применяется сразу; в рамках одной диктовки экран не меняется.
- **Устройство:** Apple GPU (Metal/MPS, FP16) или CPU (INT8). Изменение автоматически перезагружает модель; настройки показывают фактическое устройство движка.
- **Режим:** быстрый (`beam_size=1`) или точный (`beam_size=5`). Меняется поиск вариантов, а не размер модели. Применяется автоматически.
- После изменения **путей Python / модели** нажмите «Перезапустить модель».

Меню, настройки, индикатор и сообщения приложения переведены. Системные запросы разрешений следуют языку macOS; исходные диагностические сообщения сторонних библиотек могут оставаться на английском.

Модель загружается один раз и остаётся в памяти. GPU прогревается до сообщения о готовности. Подготовка аудио и детектор речи могут использовать CPU. GPU-режим не означает использование отдельного Apple Neural Engine.

## Поведение

- Порядок нажатия Control / Globe не важен; стрелки не принимаются за физическую клавишу Globe.
- Отпускание любой клавиши заканчивает запись. Esc отменяет запись, распознавание отменяется через меню. Пока распознавание или вставка не завершены, новая запись не начинается.
- Запись останавливается через три минуты, при сне/деактивации сеанса, проблемах с аудио или отзыве необходимого разрешения.
- Окно не забирает фокус и не перехватывает клики. Спектр из 25 частотных полос отражается относительно центра. Для распознавания используется другая бегущая волна. Учитывается Reduce Motion.
- Определение и проверка поля через Accessibility выполняются в фоне. Перед ⌘V проверяются исходное приложение/окно/поле, действия пользователя и отпускание модификаторов.
- Клик, ввод текста или смена приложения/Space после начала записи запрещают автоматическую вставку, даже если вернуться обратно. Результат копируется локально для ручной вставки. Если буфер изменился непосредственно перед отправкой, фраза остаётся доступной в меню/настройках.
- Для Electron и веб-редакторов с неполными данными Accessibility используется проверка неизменного окна. Пересозданные текстовые поля сопоставляются по роли, идентификатору и геометрии. При недостаточных данных выполняется только копирование.
- Исходный буфер восстанавливается через секунду, если его никто не менял. Быстрые последовательные диктовки сохраняют общий исходный снимок. Новое копирование пользователя не затирается восстановлением.
- «Текст отправлен» означает отправку ⌘V процессу приложения, а не подтверждение вставки со стороны редактора. Сообщение скрывается через 0,8 секунды. Последнюю фразу можно скопировать отдельно.

По умолчанию удаляются следующие известные приписки, только в конце результата:

> Подписывайтесь на наш канал, ставьте лайки и подписывайтесь на наш канал.

> Подписывайтесь на наш канал, ставьте лайки и пишите комментарии.

Учитываются регистр, пунктуация и повторения. Фраза внутри текста и более короткие похожие фразы сохраняются. Пустой результат не вставляется. Если эта точная фраза нужна в конце диктовки, отключите фильтр. Это узкое правило очистки, а не универсальный детектор галлюцинаций.

## Архитектура и проверка

SwiftUI отвечает за интерфейс, AppKit/Core Graphics — за окна и глобальные клавиши, AVFoundation — за аудио, Accelerate — за спектр. `AppModel` связывает состояния и настройки. Распознавание работает в постоянном Python-процессе с ID запросов, тайм-аутами и остановкой при выходе приложения. Вставка, проверка фокуса и восстановление буфера выделены в отдельные компоненты. Внешних Swift-зависимостей нет.

```sh
bash scripts/test.sh
python3 scripts/test_worker.py --device mps --beam-size 5
python3 scripts/test_worker.py --device cpu --beam-size 5
```

Тесты проверяют сочетания, политику вставки, спектр, фильтр, языки, завершение аудиозаписи, восстановление отдельного тестового буфера, протокол worker и неполную модель. Проверки буфера требуют доступа к pasteboard в сеансе macOS; ограниченная песочница может его блокировать. Общий буфер пользователя тесты не изменяют.

Проверка настоящей модели с запретом любых сетевых соединений:

```sh
mkdir -p .build/fixtures
say -v 'Milena (Russian (Russia))' -o .build/fixtures/russian.aiff \
  'Привет. Это проверка локального распознавания речи.'
python3 scripts/test_worker.py --deny-network --device mps --beam-size 5 \
  --speech .build/fixtures/russian.aiff
```

Нужен уже установленный русский системный голос; список доступен через `say -v '?'`. Проверяются устройство, точность, тишина, ошибка файла, речь, повторные запросы и выход по EOF. `--deny-network` запрещает сеть средствами macOS и отслеживает Python socket/DNS-вызовы. Это тест для разработки, приложение от `sandbox-exec` не зависит. GPU-тесту нужен доступ к Metal.

Ручная приёмка: оба порядка клавиш и отпускание каждой, TextEdit и браузер/Electron, смена поля, Esc, сон/блокировка, отключение микрофона, несколько экранов, полноэкранные окна, оба языка и переключение CPU/GPU. Подробности аудита и оставшиеся ограничения — в [docs/AUDIT.md](docs/AUDIT.md).

## Подпись и публикация

Скрипт создаёт ad-hoc-подписанный `dist/Dictation.app`. Для личного использования Apple Developer account не нужен. После пересборки или перемещения могут понадобиться повторные разрешения; используйте постоянный путь. Можно передать существующую подпись через `DICTATION_SIGN_IDENTITY`. Developer ID notarization, установщик и автообновления пока не настроены.

Сборки, виртуальные окружения и приватные настройки исключены из Git. Модель и Python-пакеты находятся вне проекта. Лицензия для публикации исходников пока не выбрана.
